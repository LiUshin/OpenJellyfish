# OpenJellyfish — 平台使用指南

欢迎使用 OpenJellyfish！本文帮助你了解平台能做什么、以及如何让 Agent 帮你完成工作。

---

## 平台功能

### 对话

- 与 AI Agent 进行多轮对话，支持流式输出
- 管理多个对话，自动生成标题
- 用项目按主题整理多个对话；每个项目保存一份可编辑的 Markdown brief，并支持项目内搜索
- 在管理员对话中选择一个 Service 开启测试模式；测试问答留在当前对话，关闭后可请管理员 Agent 根据结果调整 Service
- Agent 会记住每个对话的完整上下文，切换回之前的对话时能继续
- 支持语音输入（单击麦克风开始/停止，自动转写填入输入框）
- 支持图片上传与识别

### 可选 Codex / Cursor 引擎

v1.3.0 支持在管理员主聊天选择获授权的 Codex / Cursor 模型。部署方在 `/superadmin` 管理供应商连接并授权可信 admin；DeepAgents 保持默认。管理员个人微信、授权的 Agent 定时任务和语音后台委派也已有 CLI 代码路径，真实渠道验收范围见 [标准运行模式](runtime-standard-mode.md)。未来 Plan 与更多 CLI mode 的统一契约见 [设计草案](runtime-plan-mode-contract.md)；部署与登录见 [主机超管控制台](superadmin-console.md)。

### 文件系统

- 每个用户拥有独立的虚拟文件系统；聊天、服务、定时任务、环境和设置页都可通过页眉按钮打开右侧文件面板
- 支持浏览、上传、下载、编辑、重命名、删除、拖拽上传
- 文件分为三个主要目录：
  - `/docs/` — 文档目录，存放参考资料和输出文件
  - `/scripts/` — 脚本目录，存放可执行的 Python 脚本
  - `/generated/` — Agent 生成的内容

### 产品导航与设置

桌面左侧是仅显示图标的一级栏，悬停显示名称：**聊天、服务、定时任务、环境**；底部是设置和用户图标，退出登录位于用户菜单中。二级栏顶部只显示 OpenJellyfish 名称、明暗切换和语言切换。服务的二级区域包含“我的服务”和“收件箱”，服务图标显示收件箱未读数。环境集中模型/API/CLI 连接配置及 Python 依赖，通用设置位于设置菜单。右侧文件浏览与预览可与任何一级区域并存；窄桌面和手机使用浮层或抽屉，避免压窄正文。

设置页保留操作规则、Subagent、个人微信、用量和备份等入口。实时语音设置页的导航入口暂时隐藏，已有代码仍保留；下表列出各区域已有功能：

| 页面 | 功能 |
|------|------|
| **操作规则** | System Prompt、用户画像、Memory & Soul、能力提示词 |
| **Subagent** | 配置子 Agent（默认内置 memory 等） |
| **Python 环境** | 每用户独立 venv，安装脚本依赖 |
| **环境 / 通用设置** | 环境管理模型与 API/CLI 连接；通用设置管理时区、界面样式、YOLO 模式和高级功能开关。批量运行入口暂时隐藏 |
| **数据备份** | 按模块导出/导入 ZIP |
| **用量统计** | LLM Token 按 Agent Core、模型、渠道等维度查看；未上报用量的 CLI 运行单独提示 |
| **语音（入口暂隐藏）** | LiveKit 实时通话调音台（需部署方配置） |
| **Service 管理** | 发布服务、API Key、微信渠道、使用情况 |
| **定时任务** | 列表 / 谱系图 / 时间轴，支持 spawn 子任务 |
| **微信接入** | 管理员主 Agent 微信对话 |
| **收件箱** | 持久反馈、管理员回复与逐条投递状态 |

### 主题与样式

- **明暗模式**：点击二级栏顶部 OpenJellyfish 旁的太阳/月亮图标切换
- **界面样式**：在 设置 > 通用设置 > 界面与时间 中选择 Regular（默认）或 Terminal（等宽字体、直角、CRT 扫描线效果）

## Agent 能力

你可以通过对话让 Agent 帮你完成以下事情：

### 文件与脚本

- **读写文件** — 创建、编辑、搜索你的文档
- **执行 Python 脚本** — Agent 可以编写并运行 Python 代码，支持 numpy、pandas、matplotlib、plotly 等数据科学库
- **展示媒体** — 生成的图表、音频、视频、PDF 可以直接在对话中展示

### 信息检索

- **网络搜索** — Agent 可以搜索实时信息
- **网页抓取** — Agent 可以获取并解析指定网页内容
- **深度研究** — 可配置 research 子 Agent，多步骤调研（需自行在 Subagent 中启用）

### 计划与审批

- **任务计划** — Agent 可以提出分步计划，你审批后逐步执行
- **人机协作** — 关键操作可配置为需要你确认后才执行

### 定时任务

- 告诉 Agent 你需要定期执行的事情（如"每天早上 9 点汇总新闻"）
- Agent 会自动创建 cron / 一次性 / 周期性 定时任务
- 可通过微信等渠道推送执行结果

### AI 生成

在对话头部的能力开关中启用后，Agent 还可以：
- **生成图片**（DALL·E）
- **生成语音**（TTS）
- **生成视频**

### 记忆

- **memory 子 Agent** — Agent 可以回溯你的历史对话、检索跨对话信息
- **Soul 编辑**（可选）— Agent 可以自主更新系统 Prompt 和用户画像来优化自身表现
- **项目 brief** — 项目内对话每轮读取同一份摘要并注入上下文，注入预算不超过 5,000 token；文档和服务记录仍按各自原有范围管理

## 定制 Agent 行为

### System Prompt

在 设置 > System Prompt 中编辑 Agent 的核心行为指令。可用占位符：

| 占位符 | 说明 |
|--------|------|
| `{today}` | 自动替换为当前日期（精确时间按消息级时间戳注入，不再用 `{time}`） |
| `{user_profile_context}` | 自动插入用户画像信息 |

每次保存会自动创建版本快照，可随时回滚。

### User Profile

在 设置 > System Prompt 中编辑用户画像，告诉 Agent 你的背景和偏好，Agent 会据此个性化回答。

## Service（对外服务）

你可以将 Agent 能力打包为 Service 供外部用户使用：

1. 在 服务 > 我的服务 中创建 Service
2. 选择 Prompt 版本、可访问的文档、允许的能力
3. 生成 API Key 供外部调用
4. 可选接入微信，让微信用户直接与你的 Agent 对话

Service Agent 按发布时配置的文档范围工作。Service Key 是服务级凭据，不是每个消费者的独立登录身份。

**在管理员对话测试 Service：**选择自己的 Service 并开启测试模式，后续消息会按该 Service 当前保存的引擎、模型、Prompt 和工具范围执行；草稿也可测试。测试历史与真实使用者会话隔离，不进入 Service 记录或收件箱。`contact_admin` 在测试时仅模拟提交。关闭模式后，管理员 Agent 可以读取本对话中的测试问答并继续修改；如果 Service 配置已变化，先关闭并重新开启测试模式。详见 [测试模式设计与验收](service-test-mode-design.md)。

- **反馈与回复**：Service Agent 调用 `contact_admin` 后，反馈先持久保存到管理员收件箱，每条新反馈排队提醒管理员微信；未连接时保留待重试。管理员从收件箱回复，或在自己的微信发送 `回复 inbox_反馈编号：正文`，服务端只向原消费者会话投递。
- **直接通知**：在 Service 管理的广播功能中选择已有会话并填写正文，可立即发送或指定时间。网页自动补拉消息，API 客户端使用事件游标拉取，微信通过原会话绑定投递。
- **Service Agent 任务**：需要模型执行任务时使用定时任务，能力由执行授权限制。运行成功与消息送达分别记录；普通运行说明不会自动发给消费者。

收件箱的已读、已回复、已解决与投递状态分别显示。“已记录”不代表对方收到；微信结果未知时不会自动重发。当前回复和直接通知仅支持文字。详细接口、迁移和恢复说明见 [Service 消息](service-messaging.md)。

## 常见问题

**Q：Agent 能记住之前说过什么吗？**
能。每个对话的上下文会完整保存，切换回去时 Agent 能继续之前的话题。memory 子 Agent 还可以跨对话检索你的历史信息。

**Q：脚本执行有什么限制？**
脚本在独立沙箱中执行，有超时限制。可用的 Python 包可以在 环境 > Python 依赖 中查看和安装。

**Q：如何让 Agent 定期执行任务？**
直接在对话中告诉 Agent，如"每周一早上帮我生成周报"。Agent 会自动创建定时任务，你可以在左侧「定时任务」中管理。

**Q：如何批量处理数据？**
批量运行入口暂时隐藏，现有执行能力仍保留。
