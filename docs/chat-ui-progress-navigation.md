# 聊天进展与左侧问答导航

## 展示行为

- 主聊天、Codex / Cursor 会话、Service 网页共用进展展示与左侧导航。
- 执行过程按原顺序展示正文、相邻工具组和可见子任务；工具可逐层展开到输入、结果。文件编辑、计划、定时任务继续使用已有专用组件。
- 工作阶段默认展开，手动收起会保持到阶段切换。等待审批和结束时默认收起；恢复工作时展开。审批控件在过程窗口外保留。
- 结束后的回答取最后一个工具/子任务之后的正文，直接放在过程窗口外。没有工具的纯文本回答直接展示。运行失败或停止时保留已生成内容。
- 进展窗口限制高度，只有贴近底部时自动跟随；向上滚动或展开详情会暂停跟随，可点「回到最新进展」。已收起且未打开的历史过程延迟渲染内容。
- Runtime 经过时间来自真实创建/完成时间，包括排队和等待审批；无时间戳的旧记录不补造计时。
- Service 继续使用其工具白名单文案，不在普通工具详情或摘要中暴露输入、结果及内部子任务。

## 左侧导航

位置保留在聊天区域左侧。普通短杠宽 9px，当前阅读项 16px，悬停项 30px，邻项每级递减 6px；沿用主题颜色与荧光阴影。

预览只取问题和可见正文回答，不读取推理、工具参数或结果。预览通过 portal 展示，避免被导航滚动区域裁切。点击跳转与滚动高亮保持联动。

长列表只挂载可视行和缓冲行。支持方向键、Home / End、Enter 与 Escape。鼠标或键盘正在操作时暂停自动移动导航轨道。开启「减少动态效果」时关闭新动画与顺滑跳转。

## 验证

在 `frontend` 目录运行：

```bash
npm run test:chat
npm run build
```

浏览器脚本需要 Playwright 和 Chromium。可使用已有安装，或在单独的工具目录安装；通过 `PLAYWRIGHT_MODULE` 指向模块目录，`PLAYWRIGHT_CHANNEL` 选择已安装的浏览器（默认 `chromium`）。

先启动 Vite：

```bash
npm run dev -- --host 127.0.0.1 --port 3004 --strictPort
```

再运行：

```bash
node tests/chat-presentation.browser.cjs
node tests/chat-integration.browser.cjs
```

`TEST_BASE_URL` 可覆盖默认的 `http://127.0.0.1:3004`。组件脚本检查阶段折叠、滚动位置、最终答案、工具失败、千条导航键盘操作、Service 信息过滤、窄屏和减少动态效果。完整页面脚本使用模拟 API 检查自挂模型、Codex、Cursor 历史和审批恢复。截图输出到系统临时目录。

这些验证覆盖前端展示与交互，不包含线上部署或供应商真实模型请求。构建仍有已有的大 chunk 提示；独立组件验收页在部分 Chrome 版本中会出现本地 HMR WebSocket 权限提示，不影响组件断言。
